**Klaud is now Beluga, and it stays calm while plans run.**

- **Klaud is now Beluga**: this update installs Beluga in Klaud's place and renames the app to `Beluga.app`. Your settings, window, chats, plans and tasks come along (`~/.klaud` becomes `~/.beluga`, with a link back). Old `klaud://` invites and links still open. macOS asks once more for notifications, and a Focus that allowed Klaud needs Beluga added.
- **New names elsewhere**: the repo is [kayraucklnc/beluga](https://github.com/kayraucklnc/beluga) (old klaud links redirect), and the CLI is `beluga-code` on npm.
- **Responsive under parallel plans**: no more re-render storms or busy refreshes while many tasks run; typing, scrolling and switching stay quick.
- **Honest chat progress**: steps fold away when they finish, background work shows as rows in the timeline, nothing looks like it's still running after a crash or quit, and connection trouble is one calm status.
- **Plan page**: the plan and its chat on one page, with a crisp canvas that reads milestones → criteria → next milestone and shows whole task titles. A finished task looks finished.
- **Faster tests**: unit tests and e2e specs run side by side without swamping the Mac.
