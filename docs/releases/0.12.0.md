**Your env files open in Beluga, and tasks finish when their work does.**

- **Your env files are yours**: a project's `.env` shows in your own Files pane, never to friends. Your own Claude asks before it reads or changes one (Allow once, Always for this project, Always, or Don't allow). You can take an "always" back in Settings › Environment.
- **Database views find your Postgres**: from `DATABASE_URL` and the like, set in Settings or in the project. A Supabase URL plus its database password is enough. Settings has a new **Test Connection** button.
- **Variables are the same everywhere**: views see exactly what Claude's Bash sees. A shell or dev server started before a change offers **Restart**, and the room warns you once before you send something that looks like a password.
- **Tasks finish when their work does**: a worktree that moves a task along carries it, so its merged PR marks the task Done, and a parent that's done takes its sub-tasks with it.
- **Claude uses tasks unasked**: a message that asks for several things gets a task for each, and `task:KEY` chips and task cards show up in chat.
- **A task Archive**: Archive Done in one click, plus Restore and Delete for Good. Archiving shrinks proof screenshots to a few KB.
- **Every chat keeps its own draft**: that includes each project's new-worktree box, so a draft can't go to the wrong chat.
- **Project home**: it keeps its shape beside a wide right panel, its terminal opens in that project, and a pasted image waits as a thumbnail.
- **Images in the message box**: Backspace removes an image whole, and a queued message you pull back gets its images back.
- **The file editor's caret stays on its line**, even in long files.
- **Chat**: what Claude says between steps reads as separate paragraphs.
- **Beluga Lite (the terminal app on npm) is retired**: the Mac app is the only Beluga now.
