**Beluga 1.5: fork a friend's worktree to your Mac, bring in Claude Code conversations from outside Beluga, and Sentinel on one page.**

- **Fork a friend's worktree**: its commits, uncommitted work, Scratch and conversation come over to your Mac, and your Claude remembers what happened there.
- **Bring in a Claude Code conversation**: the project's ••• lists the conversations you had with Claude Code in its folder (or any folder you choose), and continues one in a new worktree with Claude resuming it there.
- **Sentinel is one page**: Needs you, At a glance with what came back, and Watching, with the Sentinel chat docked beside it. Asking about a sentinel opens that chat next to its page, and Review in Beluga opens where Claude is waiting.
- **Sentinel sources** reach Supabase over IPv4, read the current environment, and are checked before saving. Board tiles fit their shape and carry their project, and Add to the Board picks with pictures.
- **About This Project**: a shared note about the project that Claude reads when it writes tasks. Claude fills it in from a quick look the first time you make a worktree.
- **New Task**: one message makes every task it asks for, an epic with its parts, each for the teammate it names. Tasks only go to a project's teammates, Info shows the team with a way to their chat, and epic cards have a soft tint.
- **A queued message** waits above the box instead of in the chat, and once it runs it's drawn where it ran.
- **Fixes**: a worktree chip in a chat no longer crashes the view. Mac updates are signed with the same certificate every time, so they keep Screen Recording.
- **Phone**: New Task drafts every task one message asks for, an epic with its parts, each for the teammate it names, and adds them all. The phone app is 1.5.0.

The Android app (`Beluga-1.5.0.apk`) is attached.
