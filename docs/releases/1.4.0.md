**Beluga 1.4: Sentinel watches so you don't have to.**

- **Sentinel**: a new section under Work. A sentinel runs on a schedule, when something happens, by hand, or after another sentinel; does a few steps in order (ask Claude, run a script, call a service, open a pull request, merge, notify you, message a chat, ask a friend's Claude, run another sentinel); and leaves a report. It runs on your Mac, as you, and starts paused until you Turn It On.
- **Eleven recipes to start from**: Morning brief, Fix what broke, Fix it and ship it, Nightly tests (with a sentinel that fixes the failure), Dependency updates, Release notes, Issues to tasks, Uptime guard, Failed payments, Watch the web and Review new pull requests, each with a prompt you can change.
- **Or describe it**: say "every weekday at 8, read yesterday's commits and brief me" in New Sentinel, or in any chat, and your Claude sets it up. "Ask Claude to change this sentinel…" on its page changes it later. Claude can pause a sentinel but never turn one on, and a change to what it can do pauses it until you look.
- **When something happens**: a task done, a pull request opened or merged in Beluga; a failed workflow, a new issue or a label on GitHub; a failed payment or a dispute in Stripe; a site that stops answering; a new error, a regression or a spike in Sentry; or a post to its own webhook URL.
- **Merge if acceptable**: a fix ships only when every check passes, a reviewer says ship, and you tap Merge, on the Mac or the phone. Look, Work and Ship say how far Claude may go.
- **Every run leaves a report**: the run's page has its steps, their outputs, the report and Open Chat; the row says how the last run went and when the next one is. Time limits, runs per day, and a pause after three failures in a row keep it in check.
- **Phone**: your sentinels and their runs, Run Now, Pause and Turn On, a run's report, and Merge or Not Now when a fix waits for you.
