**Beluga 1.4: Sentinel watches so you don't have to, your MCP servers come along, and friends' work reaches you even when you're never online together.**

- **Sentinel**: a new section under Work. A sentinel runs on a schedule, when something happens, by hand, or after another sentinel; does a few steps in order (ask Claude, run a script, call a service, open a pull request, merge, notify you, message a chat, ask a friend's Claude, run another sentinel); and leaves a report. It runs on your Mac, as you, and starts paused until you Turn It On.
- **Eleven recipes to start from**: Morning brief, Fix what broke, Fix it and ship it, Nightly tests (with a sentinel that fixes the failure), Dependency updates, Release notes, Issues to tasks, Uptime guard, Failed payments, Watch the web and Review new pull requests, each with a prompt you can change.
- **Or describe it**: say "every weekday at 8, read yesterday's commits and brief me" in New Sentinel, or in any chat, and your Claude sets it up. "Ask Claude to change this sentinel…" on its page changes it later. Claude can pause a sentinel but never turn one on, and a change to what it can do pauses it until you look.
- **When something happens**: a task done, a pull request opened or merged in Beluga; a failed workflow, a new issue or a label on GitHub; a failed payment or a dispute in Stripe; a site that stops answering; a new error, a regression or a spike in Sentry; or a post to its own webhook URL.
- **Merge if acceptable**: a fix ships only when every check passes, a reviewer says ship, and you tap Merge, on the Mac or the phone. Look, Work and Ship say how far Claude may go.
- **Every run leaves a report**: the run's page has its steps, their outputs, the report and Open Chat; the row says how the last run went and when the next one is. Time limits, runs per day, and a pause after three failures in a row keep it in check.
- **Actions**: watch a project's GitHub Actions live, with each workflow drawn as a graph and each job's steps inside its node while it runs.
- **Your MCP servers**: your runs get your Claude Code MCP servers (user, local and plugin, with the same names, so your logins still work). Settings › Claude lists them and signs you in to any that need it, and a plug chip in the box you type in lists them too.
- **Friends**: a project shared whole is copied to your friend's Mac (cloned, or sent as a bundle), and in a friend's worktree you pick where it runs, on their Mac or in your copy. A shared conversation's whole history loads as you scroll back, and its box locks while the owner is offline. What a friend hasn't picked up yet waits in a mailbox until their Mac is back, even if you're never online together, and closing the lid sends it first.
- **Tasks**: a task with sub-tasks is an epic and looks like a deck on the board. Labels are icons in a colour, picked from a set. A task is assigned to a person, and their card shows who's working on it. You can drop files on a task, its card or its row, and its Claude gets them.
- **The bell** lists what's waiting for you: answer it right in the list, or open it where it lives.
- **Merge into main without a PR** from the branch menu (it asks first). Merge on GitHub pushes any commits GitHub doesn't have yet, then merges.
- **Worktrees**: removing one no longer freezes the Mac. New worktrees install nested packages' dependencies and get the main folder's env files at any depth, processes you keep running outlive the turn, and the dock terminal keeps the shell's keys.
- **Picking a model mid-conversation** switches the live run before your next message, and Send Now answers your message instead of ending the run.
- **Settings › Menu Bar**: pick what the menu-bar number counts, and a whale that spouts water when Claude finishes. Profile pictures that friends keep a copy of, the microphone on the project home, and a quieter branch control and message box.
- **Phone**: your sentinels and their runs, Run Now, Pause and Turn On, a run's report, and Merge or Not Now when a fix waits for you. Pictures Claude shows by a Mac path now draw on the phone, and the phone shows which tasks are epics. The phone app is 1.4.0.

The Android app (`Beluga-1.4.0.apk`) is attached.
