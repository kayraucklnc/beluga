**Beluga 2.0.1: your project's pull requests on Project Home, and a new chat that's ready before you type.**

- **Pull requests on Project Home**: Project Home lists the project's open pull requests on GitHub, anyone's, with their author, branch, Draft, review and checks. One on a worktree's branch opens that worktree; any other opens on GitHub.
- **New chats**: before your first message, the composer already has its full controls: the mode, MCP servers, skills and custom commands. The mode you pick applies from the first message, a chat can start from a skill or a custom command, and a new worktree starts in the plan mode you picked.
- **Dashboards**: a number tile with a long value shows it whole beside its chart.

The phone app hasn't changed: it stays 2.0.0.
