**Beluga 1.6: a calmer phone app with Home-screen widgets, a project's environment in one place, and dashboards laid out like a home screen.**

- **Environment**: a project's ••• has Environment…, with its `.env` and Beluga's own variables in one list. Worktrees load the main folder's `.env` by default, a key a worktree adds goes back to the main folder by itself, and a changed value asks Copy to Main Folder or Keep Here.
- **Dashboards**: tiles stay where you drop them, anywhere on the grid like a home screen, and a bumped tile moves to the nearest free spot. Project logos show in full colour, and a number tile's Rename… shows its field.
- **Sentinel**: queries, scripts, commands and JSON bodies are in colour, with Tidy for SQL and JSON. A sentinel's workflow shows as a graph, rows have typed columns, and there's a Fetch, analyse, send recipe. Tell me when has a Sentinels switch so sentinel runs can go quiet.
- **Issues**: comment on an issue from its page, under the thread.
- **Desktop widget**: the tile you pick stays picked, so changing it changes what the widget shows.
- **Onboarding**: the tour shows Sentinel, and a sentence becomes a sentinel.
- **Chat**: a friend's Claude's request for their Mac goes there by itself, with no Ask on click.
- **Fixes**: the daemon no longer spins a core when its stderr closes, Max Fire only draws every frame while you type, the Usage cards no longer pile up on older macOS, and the right panel slides smoothly with long code previews.
- **Phone**: a calmer design (one ink, colour only for meaning), Work and Tasks folded together, Dismiss on Needs you, Remove a stuck friend request, and notifications only after 5 minutes away from the Mac. Board tiles can go on the Android Home screen as widgets. The phone app is 1.6.0.

- **Smaller downloads**: the Mac app is 59 MB instead of 220 MB (Claude Code downloads once on first launch), and the Android app is 64 MB instead of 418 MB.
- **Beluga Phone Control**: letting your Mac use your phone now takes a small second app with the Accessibility service, so the main Android app installs where Play Protect blocks sideloaded apps that have one. Phone Control installs from your Mac over a cable or Wireless debugging.

The Android app (`Beluga-1.6.0.apk`) and Beluga Phone Control (`Beluga-Phone-Control-1.6.0.apk`) are attached.
