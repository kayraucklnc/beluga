**Beluga 1.8: the phone app updates itself, knock to join a teammate's worktree, and friend chats you can edit and clear.**

- **Phone updates itself**: like the Mac, the phone app checks GitHub releases. A pill on Home offers Update Now, or turn on Update automatically.
- **Phone app, once**: from this version the phone apps are signed with Beluga's own key. Uninstall Beluga and Beluga Link from the phone once, install `Beluga-1.8.0.apk` and `Beluga-Link.apk`, and pair again. After that the phone updates itself. On the Mac, Set Up Beluga Link replaces a Link with the old key.
- **Knock to join**: knock on a teammate's worktree from its task, and they let you in as a viewer or an editor, then take it back when they want.
- **Friend chats**: delete a message (yours goes from their Mac too), edit your own, and clear the chat. On the phone, long-press a message, or Clear Chat in the •••.
- **Friend tasks have limits**: a friend's task on your Mac stops after 50 turns, 20 minutes, 8 approval prompts or 2 declines in a row, and a Claude can ask the same friend's Claude at most 3 times in 10 minutes.
- **Safer sharing**: a file that runs code asks every time, and shared-folder checks follow links.
- **Tasks**: @-mention someone in a task's comments to let them know.
- **Projects**: start a new project from Beluga, with git and a first commit. Worktrees can be deleted for good, not only archived.
- **Plan mode**: approving Claude's plan switches the conversation back to Act.
- **Continue after merge**: a divider marks where the merged pull request ends, and Claude knows it shipped.
- **Shortcuts**: the Go places move to ⌘1…7.
- **Terminal blocks**: Copy leaves the prompt out, so a command pastes as it was typed.
- **Stop and the working line**: a run stuck starting is stopped for good, so your next message runs, and the working line says what a run is waiting on (an API retry, or Claude Code downloading).
- **Lighter on a slower Mac**: the engine and the app do less work for the same results, and Settings › Appearance › Reduce Transparency gives a solid window.
- **Desktop widgets**: an old widget left running from before an update is stopped, so macOS keeps the tiles.
- **Graphs**: a graph's header in a chat is one slim line.

The Android app (`Beluga-1.8.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached.
