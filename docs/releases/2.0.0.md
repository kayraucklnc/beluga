**Beluga 2.0: on Mac, Linux, Windows and Android, boards across repos, Sentinel you can talk to, and tables you can take with you.**

- **Every platform**: Beluga 2.0 ships for Mac, Linux (AppImage, .deb and .rpm), Windows and Android in one release. Every desktop install updates itself from its own kind of package, .deb and .rpm included.
- **Boards across repos**: a repo's board shows every task that runs in it, with a chip naming the board it lives on. Start on an epic whose sub-tasks live in other repos and one agent works across a worktree in each; each repo's pull request moves its own sub-tasks. Claude can make a board for a few repos itself, and a board you made can be deleted with tasks on it (they go back to their repos' boards).
- **Sentinel**: with nothing set up, asking Sentinel's agent turns the page into the conversation, and asked about data it builds a dashboard, watcher or pipeline. The sentinels that are on sit under the sidebar's Sentinel row and unfold to their runs; a run's ••• shows it in Finder or deletes it. A sentinel's chats no longer count toward Open chats, and Keep chats picks every run, failed only, or the latest.
- **Open chats is a setting**: Your Mac and Sentinel keep 10, 30, 50, 100 or no limit.
- **Switching agents**: moving a conversation to another agent asks whether to just switch or have the old one write a handoff note first.
- **Tasks**: a task's Agent row shows who works it and opens its conversation. A card's avatar changes who the task is for, a task its agent is still writing shows a skeleton, and the @ list puts Ready tasks first.
- **Tables**: copy or save rows as Markdown, CSV, TSV, JSON or SQL, raw or as shown.
- **Friends**: forking a friend's worktree shows Copying N% and then Setting up…. A friend's profile shows how much of their Claude Code and Codex plans is left, when they share it. Away when idle turns back to Online after a reconnect, and a status you pick stays.
- **Chats**: what came in since you last read gets a New messages line, on the Mac and the phone, and the line breaks you type are kept.
- **Terminal view**: a new conversation starts as the chat and your first message opens Claude Code's terminal on it.
- **Graphs** lay out calmly, with room for every label.
- **Sign In**: an expired Claude sign-in offers /login's three choices.
- **Fixes**: plan milestones side by side wrap instead of squeezing; onboarding notices Codex installed while you're on Your agents; the model picker says Default.

The Android app (`Beluga-2.0.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached. The phone updates itself from 1.8.0 or later.
