**Beluga 1.9: Linux and Windows, any agent, and plans that run on their own.**

- **Linux and Windows**: Beluga runs there too. Download the AppImage, .deb or .rpm for Linux, or the installer for Windows; the AppImage and the Windows app update themselves. Shortcuts use Ctrl there, a friend's screenshot and device info work, and "Your Mac" is Your Linux or Your Windows. On Windows, commands Beluga runs for you need Git for Windows (Claude Code needs it too), and Windows may warn on the first install: More info › Run anyway.
- **Any agent**: pick Claude, Codex or a local model for any chat, worktree or plan, each with its own logo, and let agents talk to each other.
- **Terminal chat view**: follow a conversation the way the terminal shows it.
- **Plans that run on their own**: a checker for each milestone, plans as epics in Tasks, and no quiet stalls. Talk a draft over beside it, and @ tasks in the plan's chat.
- **Pull requests in Beluga**: comments, reviews and line threads with their code above the chat. Reply, resolve, or ask your agent.
- **A project's Files**: browse, open, edit and save the main folder, and search names (with regex) or contents.
- **/btw**: ask a side question while your agent works, answered above the box and never in the conversation.
- **Steering**: a message sent while your agent works is read at its next step.
- **Sign In**: when Claude Code isn't signed in, a failed card offers Sign In, then the run carries on.
- **Your settings**: your own Claude runs load your user settings and skills (~/.claude, plugins). A project's .claude/ still never loads.
- **Branch prefix**: new worktrees' branches start with what you choose in Settings › Workspaces (beluga/ by default).
- **Tasks**: a merge makes Done only the work done in its worktree; sub-tasks filed for later stay open.
- **Chats with friends** open scrolled all the way down and stay there while pictures load.
- **Graphs in a chat or a document** no longer take the Space key from the page.
- **Fixes**: a daemon a closed app left running is replaced, so Claude Code stays signed in; a .klaud folder no longer appears in worktrees.

The Android app (`Beluga-1.9.0.apk`) and Beluga Link (`Beluga-Link.apk`) are attached. The phone updates itself from 1.8.0.
