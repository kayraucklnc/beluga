**Beluga 3.5: pasted API keys stay out of the chat, Run on a command Claude gives you, chat schedules, and a terminal that stays smooth under a flood.**

- **Pasted API keys stay safe**: paste a key and a card offers to keep it as the chat's own variable. The key leaves the message, a key chip takes its place, and Claude gets it in its environment by name. The box's Keys pill lists a chat's keys, and Merge asks whether the project keeps them.
- **Run a command from the chat**: a shell block in your messages or Claude's gets Run beside Copy. It types the command into the terminal and puts the keyboard there. Untagged blocks of commands to paste get it too.
- **Chat schedules**: wake your own chat daily, once in a few hours, or after a usage limit lifts, from /schedule or the chat's Info panel. They run on Sentinel, and the phone can run or pause them.
- **Share with "Can take it over"**: handing off is now part of Share, and any share can come with a handoff note your agent writes (goal, where it stands, next steps).
- **Smooth terminal**: every terminal draws with WebGL, and a program flooding output waits for the screen to catch up, so typing and Ctrl+C answer at once (21 ms, down from 7 s).
- **zsh takes the bash agents write**: an unmatched glob, a URL with `?` or `[ a == b ]` no longer fails a whole command in zsh.
- **Format any file** with Beluga's own Prettier when a project has none.
- **Fixes**: an approval shows only in the chat that asked, and other chats point to it; a merge with open criteria leaves its task In Review instead of Done; images in your answers to an agent's questions reach it; pasted images nothing links to any more are cleaned up; a folder link outside your projects opens in Finder; a chat shows as working while a thread under it runs; Codex asks Beluga's permission gate for Beluga's tools, as Claude does; menus close for good on Windows; Windows and Linux say "this computer", not "this Mac"; the home page holds its shape in a narrow window; a worktree's setup shows one short toast when it's done.

The phone app is 3.5.0 too, with chat schedules, and it updates by itself.
